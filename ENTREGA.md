## Descripción del proceso

Inicialmente cree una carpeta, seguidamente utilice el comando <git init> para iniciar un proyecto git.
Agregue los archivos y carpetas de la estructura inicial, use los comandos <git add .> y <git commit>.
Cree un repositorio en GitHub, lo vincule con mi repositorio local con <git remote add origin "url"> y <git push -u origin main>.
En GitHub cree una issue para agregar contenido al README.
En local use <git switch -c "rama"> para crear una rama en donde resolver la issue propuesta.
Realice los cambios y use los comandos <git add .>, <git commit> y <git push> respectivamente.
En GitHub cree una pull request para unificar estos cambios a la rama main. Realice el merge.
Finalmente cree una rama para trabajar en el archivo ENTREGA y es precisamente lo que estoy haciendo en este momento.
