# Título del proyecto

Trabajo práctico integrador del curso "Introducción a Git"

## Descripción

El presente trabajo intenta mostrar todo lo aprendido en el curso "Introducción a Git".
Consta de una estructura inicial obligatoria y el agregado de un contenido simple.

## Objetivo

El objetivo del repositorio es simplemente evidenciar el correcto uso de los diferentes comandos Git.

## Estructura del repositorio

tp-integrador-git-apellido-nombre/
│
├── README.md
├── ENTREGA.md
└── proyecto/
    ├── index.html
    └── styles.css

El archivo <README.md> contiene (o debería contener) información pertinente al proyecto.
El archivo <ENTREGA.md> contiene (o debería contener) información pertinente al trabajo práctico.
La carpeta <proyecto> contiene los archivos que simulan ser archivos de un proyecto, por ejemplo una landing page.
El archivo <index.html> es la estructura html del proyecto.
El archivo <styles.css> es la hoja de estilo del proyecto.
